# HoyOS flow map (canvas v1.5 codes, routes from `routes.json`, v0.8.0)

Codes are the canvas artboard ids; the **Route** column links to the screen in this app (hash routes, live when read at `/#/docs/flow-map`). Built vs stub status per code is at `/#/dev/specs`. **98 routes, 85 codes**, every one of them routed. Source of truth for prices is `src/tenant/pricing.ts` (Modelo de Valor v3); for policies, M-08 (`/#/admin/settings`). The tables below are generated by `npm run flow-map` from `docs/screenshots/routes.json` (each route's real spec, published by the app on `window.__hoyos.routes`); the **Dependencies** section is hand-written.

Names are the spec names (EN · ES); a code with several routes (M-03, K-03, A-06, C-08 / C-08b…) lists them all. M-08 is a family: M-08a…M-08f are its routed sub-pages (`docs/pages/M-08.md`); policies such as the cancellation window are read from M-08a, not written here.
