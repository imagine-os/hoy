# Internationalisation

- Default language: **Spanish**. Toggle to English with `LangToggle`; the choice persists in
  localStorage (`hoyos.lang`).
- Every module exports `strings: Record<string, { es: string; en?: string }>`. `src/i18n/` merges
  them at startup (the registry does it).
- `const t = useT(); t('customer.home.title', { name })` — `{name}` placeholders are interpolated.
- Missing English → Spanish. Missing key → renders `⟨key⟩` and `console.warn`s in dev builds.
- Keys are namespaced `module.section.key`. Shared strings live in `src/i18n/core.ts` under `core.*`.
- Dates and prices format with `Intl` using `es-CO` / `en-US`; currency is COP.
