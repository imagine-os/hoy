## Logic and integrations
- Attendance can be marked from T−15m to T+2h; later needs the coordinator.
- Descriptions submitted by teachers go to the coordinator for approval before publishing.
- Named reviews visible only when the student did not mark them anonymous or private.
- Payroll shows classes taught, rate, substitutions and adjustments; the amount is read-only.
- Integrations: Wompi

## States
- No class today: schedule promoted
- Attendance locked: read-only with reason
- Payroll pending: 'run closes on the 15th'

## Real vs mock
- Real: the page renders from the data layer (`useData()` / `useTable`) over the tables above; every write goes through the `DataProvider` so the Supabase provider replaces the mock unchanged.
- Mock / pending: Wompi are simulated or deferred; data is the browser-local `MockProvider` seed.
- Note: Mobile-first inside PhoneShell.
- Note: Substitution requests are written to audit_log (action substitution.request) for the coordinator.
