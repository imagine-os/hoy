## Logic and integrations
- Templates: the 72 emails of `src/data/emailCatalog.ts` (0055) — 38 to customers, 33 to teachers, 1 to the team — each with its recipient, priority, trigger and deep link. Inventory and gaps: `docs/reference/automated-emails.md`.
- Every template deep-links into the matching app screen or website page.
- Receipts include the DIAN electronic invoice reference.
- Version history with rollback; a test send never touches the real send log.
- Integrations: Wompi, Email, Supabase Auth, Supabase Realtime, DIAN e-invoicing

## States
- Unsaved changes: sticky save bar
- Missing translation: blocked from activation
- Provider error: banner with retry

## Real vs mock
- Real: the page renders from the data layer (`useData()` / `useTable`) over the tables above; every write goes through the `DataProvider` so the Supabase provider replaces the mock unchanged.
- Mock / pending: Wompi, Email, Supabase Auth, Supabase Realtime, DIAN e-invoicing are simulated or deferred; data is the browser-local `MockProvider` seed.
- Note: body_mjml stores a JSON {es,en} plain-text body until the MJML designer exists.
- Note: Versions are the audit_log rows of the template; rollback restores the before value.
- Note: Test send writes a `message_log` row — `direction outbound`, `source manual`, `subject` = the template subject, `sent_by` = you, `payload.test = true` — so it is excluded from the customer conversations (M-06 / S-06) and shows only in this log.

## 0055 — the automated email inventory (2026-10-03)
Lore's three inventories (website, customer app, teacher app) are in M-04: 72 templates in ES and EN. Tabs by recipient
(Clientes · Profesores · Equipo), a priority filter (Antes del lanzamiento · Primeros 60 días · Después) and the list
grouped by priority. Each email shows when it sends, its priority, whether a screen already promises it, whether it is
marketing (needs opt-in), whether the channel is still email-or-WhatsApp, and what the 2026-10-02 inventory said. The
editor sets recipient and priority (`email_templates.audience`, `priority`). Only the receipt is on.
