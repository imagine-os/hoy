## Logic and integrations
- Documentation rule: every change is logged with the prompt intent, the decision taken, the files touched and the version.
- Decisions record the alternative rejected, not only the choice made.
- The board is updated in the same turn as the work, never afterwards.
- Versions are switchable so any earlier state stays reviewable.
- Integrations: Supabase Auth

## States
- Current version
- Historic version (read-only banner)

## Real vs mock
- Real: the page renders from the data layer (`useData()` / `useTable`) over the tables above; every write goes through the `DataProvider` so the Supabase provider replaces the mock unchanged.
- Mock / pending: Supabase Auth are simulated or deferred; data is the browser-local `MockProvider` seed.
