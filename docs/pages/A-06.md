## Logic and integrations
- Each document is versioned; consents record which version was accepted.
- Colombian data protection: Ley 1581 de 2012 and Decreto 1377 de 2013 sections are required.
- Same content served to app and website from the CMS.
- Anchors are stable so emails can deep-link to a clause.
- Integrations: Email, Supabase Auth

## Real vs mock
- Real: the page renders from the data layer (`useData()` / `useTable`) over the tables above; every write goes through the `DataProvider` so the Supabase provider replaces the mock unchanged.
- Mock / pending: Email, Supabase Auth are simulated or deferred; data is the browser-local `MockProvider` seed.
