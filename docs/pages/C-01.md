## Responsive layout (0025)
**Shell** `AppShell` (D-0006). Below 900 px: brand top bar, a content column of at most 560 px and the sticky bottom dock (Home · Schedule · History · More), exactly the phone layout. From 900 px (`useMinWidth('shell')`): a full-viewport page, the primary nav moves into the top bar (`NavBar variant="top"`), content sits in a centred `--w-app` container (75rem, growing with the `--ui` band at 1920 / 2560 / 3840) and the document scrolls. No phone bezel at any width; the bezel exists only in the hub's `DeviceFrame` simulator.

- **≥ 900 px** (`SplitSections`, `.cust-home-split`): the greeting (`TopBar (logo, avatar, bell)` section) spans the width; the left column (1.5fr) holds the next class, today's classes and every other main section; the right column (min 18rem, 1fr) holds `MembershipNudge`, `AnnouncementCard`, `QuickActions ×4`, `StatsRow ×3` and `FeedbackPrompt`. Greeting at `--fs-3xl`.
- **< 900 px**: the sections render flat in the layout editor's order, unchanged from the phone.
- The layout editor's order is kept inside each column.

Verified 2026-09-28 at 390 · 1280 · 3840 px (ES, light) during the 0025 build; `PageSpec.checkedAt` = `[390, 1280, 3840]`. The full 360…3840 matrix is a follow-up.

## Logic and integrations
- Blocks render in priority order; each is independently toggleable in Admin → Features.
- Feedback prompt appears only for a class attended in the last 72h and not yet rated.
- Membership nudge hides for active members and for staff.
- Countdown shows under 24h, otherwise the weekday.
- Today's list is in start-time order (the A-05 intention sort was retired in 0030).
- Practice block (0040): every number is `usePracticeStats()` over `src/data/analytics.ts` — a visit is a `checked_in` booking dated by the **session** start; the streak is weekly (Mon–Sun), met when visits ≥ the goal, one rest week per rolling four, paused weeks skipped, best kept; goal 0 hides the streak tile (two-tile grid) but keeps the counts. `useMilestoneRecorder` writes events idempotently; a milestone recorded this session and ≤ 14 days old shows "¡Clase número {n}!" once. Same numbers as C-27, C-22 and the M-06 Práctica tab. Rationale and glossary: `docs/reference/analytics.md`.
- Integrations: none

## States
- Loading: skeleton cards, no layout shift
- Empty: no bookings → 'Reserve your first class'
- Error: cached feed + retry chip
- Offline: last fetch with stale badge

## Real vs mock
- Real: the page renders from the data layer (`useData()` / `useTable`) over the tables above; every write goes through the `DataProvider` so the Supabase provider replaces the mock unchanged.
- Mock / pending: no external integrations; data is the browser-local `MockProvider` seed.
