## Logic and integrations
- Every content entity has EN and ES fields; publishing requires Spanish, English optional with fallback.
- Draft → review → published, with scheduled publishing.
- Teacher edits to their own profile enter review rather than publishing directly.
- Price changes never alter existing subscriptions retroactively.
- Media library holds photos and video; placeholders are flagged until real assets land.
- Integrations: none

## States
- Loading: table skeleton
- Validation: field-level errors in the drawer
- Conflict: concurrent edit warning
- Empty: 'Create the first class type'

## Real vs mock
- Real: the page renders from the data layer (`useData()` / `useTable`) over the tables above; every write goes through the `DataProvider` so the Supabase provider replaces the mock unchanged.
- Mock / pending: no external integrations; data is the browser-local `MockProvider` seed.
- Note: Pricing is not editable here: prices live in src/tenant/pricing.ts (P-01).
- Note: Publish state = the active column of each table.
