# HOY homepage Meta Pixel pilot

One optional, browser-only PageView on the exact public homepage at https://hoyhumanclub.com/. No Purchase, checkout, registration, server events, Conversions API, browser test code, or event payload with customer fields. This is separate from PR #173's broader inert fixture.

The Railway operator switch is a digest of a one-off, 32-byte random base64url key, supplied as `HOY_META_HOME_PILOT_DIGEST`. It is off when missing and inert outside the exact production host. The human operator manually enters the key on the public home page. Only its digest lives in Railway; never put the raw key in a URL, support message, file or repo. The app accepts a correct key only in a same-origin iframe POST and consumes it server-side before returning the frame, with a 15-minute window from handler startup. This is one-time per process, not across restarts/replicas: a live smoke must use one healthy web process and no concurrent replacement, promptly clear the key after use, and not repeat an uncertain or interrupted test. Do not set the switch merely to deploy the code. Screen copy and authorized ad measurement, including what the Meta SDK might collect and the handling of privacy choices, require review before enablement. No persistent consent; abandoning the page or stopping measurement removes the frame. Stopping cannot recall an event already sent. The isolated iframe is not allowed DOM/storage access to the top page and sends no referrer. Possible loss of attribution or vendor incompatibility with an opaque origin must not be fixed by allowing access to the parent. Its source URL may be the clean frame URL instead of the home URL. No automatic config or explicit matching parameters are enabled by HOY.

Checks: `node scripts/meta-home/contract.mjs`; `node scripts/meta-home/server.mjs`; `CHROMIUM_PATH=/path/to/chrome node scripts/meta-home/browser.mjs`; `npm run typecheck`. The browser test intercepts every request and replaces the vendor SDK with a stub; it cannot prove real Meta SDK compatibility, received events or correct attribution. Before enabling a real test, check the genuine SDK in an intercepted browser and inspect all computed network metadata; include refusal, private URL, and opt-out behavior. Complete the repository's T3 independent reviews, security audit and two named release approvals. Test deployment keeps external transport off. For the approved live smoke only, coordinate first with Events Manager operator; use one clean home visit, explicitly allow it, and verify one browser PageView without fake sales or server requests. Record the time, exact event and known source limitation. To stop after the smoke, remove the digest under the normal deployment controls. Confirm off/404. If the SDK cannot meet the safety or efficacy checks, leave the flag off.
