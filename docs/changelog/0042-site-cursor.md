prompt: docs/prompts/0042-site-cursor.md
intent: Justin (owner): the website's mouse cursor looks tacky — make it fit the app's colours and work well in dark and light.
decision: A token-only cursor. The dot is `--color-ink` (6 px, 4 px over interactive elements) with a 60 % `--color-surface` hairline; the ring is `--color-primary` (28 px at 55 %, 40 px at 90 % over links and buttons, 22 px pressed, hidden over reading text) with a 45 % surface hairline on both sides of the 1.5 px stroke so it reads over the primary button and photos. The ring trails the pointer with a rAF lerp (0.22) that stops when it converges. A class tone only tints the ring (`color-mix(in srgb, var(--tone-<id>-dot) 60%, var(--color-primary))`); the per-tone halo shapes (`data-element` moss / clay / river), glows and gradients are removed. Transitions use D-01 `--dur-base` (200 ms) and `--ease-out`. Sizes stay px on purpose (they match the OS pointer, which scales with device pixel ratio, not with the `--ui` band) and live in local custom properties, so `ElementCursor.css` leaves the spacing baseline (8 → 0; baseline 71 → 63).
rejected: (1) A `mix-blend-mode: difference` cursor — it inverts to unpredictable colours over the brand blue and the warm photos, so it never looks like the app. (2) Keeping the orb with muted colours — still a glowing object competing with the content, and the per-tone shapes read as a gimmick.
