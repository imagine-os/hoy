The canvas hoy-brand colour tokens are carried whole (`palette` → `--hoy-c1…c26`, `rgb` → `--m-primary/shade/ink/mid/sun/steel/cream/light/paper`) so every derived value is auditable; semantic roles are read off the `.canvas[data-brand="hoy"]` rules (frame `.surf` #FBF7EF, tiles `.surf2` #F5EEE1, `.lane` #F1E7D2, ground #E7DCC6, `.ink` #1C2E42, body #24384F, `.dim` #4C5D70, accent --c1 #35597D on --c13 #F5EEE1, `.inverse` #35597D/#F1E7D2, pricing badge #F7F3B2/#4A4212, `--dg` #7E3B2C). The Depth detail layer's shadow recipes are copied verbatim into `--shadow-card` (surf2), `--shadow-raised` (surf), `--shadow-frame`, `--shadow-accent`, `--shadow-inverse`, `--shadow-lane`, `--shadow-pressed`, written against the RGB triplets so dark re-colours them (dark uses the canvas's black-based `.surf` shadows). The Texture detail layer becomes five CSS tokens (`--tex-lane`, `--tex-surf`, `--tex-accent`, `--tex-paper`, `--tex-ph`) applied as `background-image`; `--tex-*-on` switches turn them off in dark and wireframe exactly as the canvas does. The D-01 artboard's materials (Sand/Light/Sky/Deep/Linen) and surface scale (card/elevated/pressed/soft/inverse) are exported and rendered on `/#/dev/tokens`. Movements use `movSets.hoy` exactly. Radii gain `--r-xs 4`, `--r-ctl 11`, `--r-frame 18`, `--r-phone 34`; motion gains `--dur-spin 1.1s`; type gains `--fs-2xs 11px`, `--ls-tight -0.02em`, `--ls-eyebrow .14em`, `--fw-light`. The accent is split into `--color-primary` (accent as text/links; dark → `--cat` #9BC0E4) and `--color-accent-fill` (accent as a fill; #35597D in both themes, as the canvas keeps `--c1` constant in dark). Shells: `PhoneShell` becomes the canvas phone frame from 900 px (430 wide, `--r-phone`, frame gradient + surf grain, `--shadow-frame`, scrolls inside itself so the dock sits at the bottom of the frame, sand ground with lane grain behind); `DesktopShell` sidebar is the cream lane with the inset edge and the accent pill for the active item; top bars are `rgba(cream,.9)` with the `rgba(--m1,.18)` hairline. Components drop hairline borders in the styled skin (`--color-card-border` is transparent, wireframe sets it to #C9C4B8) and rely on the inset highlight + contact + soft shadow like the canvas tiles; primary buttons/selected chips/active segments/active dates carry the accent grain and `--shadow-accent`. Fonts stay on Google Fonts (`display=swap`) with metric-adjusted `Inter Fallback` / `DM Sans Fallback` `@font-face` (`size-adjust`, `ascent/descent-override` over Arial/Liberation Sans) so offline renders and the screenshot pass keep the same rhythm.
rejected: (1) Texture as image files (PNG/SVG noise per surface) — the canvas itself draws the suede grain with two 1 px repeating gradients plus a radial light pool; copying that recipe is exact, weighs nothing, recolours with the theme through `rgba(var(--m-shade))`, and needs no asset per component. An SVG `feTurbulence` data-URI was tried on paper and dropped: it does not match the canvas and costs paint time on long admin pages. (2) Keeping the archive (sand-and-olive) palette as `data-brand="archive"` — it would need a second semantic map, a second movement set and a second material set for a brand the canvas marks "not for production"; the canvas file remains the reference for it. Dropped. (3) One `--color-primary` for fills and text — in dark the canvas keeps accent fills deep blue and lightens only text accents (`--cat`); a single token gave either unreadable links or washed-out buttons, so fills use `--color-accent-fill`. (4) A fixed, document-scrolling phone column on desktop — the dock then floats mid-page in full-page captures and the frame never shows its bottom radius; the self-scrolling frame is what the canvas artboards show. (5) Self-hosting Inter/DM Sans — not possible offline in this environment; the metric fallbacks close most of the gap. (6) Playfair Display for display moments — the hoy brand in the canvas overrides `.serif`/`.disp` to Inter; no serif remains.

## Could not match
- Fonts in the screenshot pass are the metric fallbacks (Liberation Sans), not Inter/DM Sans, because captures run
  offline; in a browser with network the Google Fonts load. The canvas renders offline with DejaVu for the same reason.
- The canvas artboards are 340 px wide mock frames with 9–13 px type; the app renders real 390 px screens with a
  readable 14–16 px scale, so densities differ by design. Placeholder photography (`data-ph`) is not reproduced.
