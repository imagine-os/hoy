## Directives (the contract for chapter authors)

Each directive sits **on its own line** unless noted. Unknown names or keys render an explanation listing what exists.

| Write | Renders |
| --- | --- |
| `> EN HOYOS: S-02 Puerta -> busca el nombre -> Check-in` (or `> IN HOYOS:`) | A compact muted "screen box": the label as an eyebrow, bare page codes (`S-02`, `M-08a`) as mono chips, `->` as →. Continuation lines starting with `>` stay in the box. Counted as `screenBoxes` by docmeta. |
| `> NOTA: …` / `> NOTE: …` (also `TIP`, `CONSEJO`) | Note callout (unchanged). `> DECISIÓN PENDIENTE:` still feeds K-04. |
| `{{for:teacher,front_desk}}` … `{{/for}}` | A scoped passage (role ids from `src/auth/roles.ts`). Lens all or matching: shown with "Para: Profesor/a, Recepción". Lens not matching: a closed `<details>` "Solo para …". Never removed. Keep a block inside one `##` section or wrap whole sections — a `##` inside an open block does not split sections. |
| `{{editable:owner}}` / `{{editable:coordinator}}` | Anywhere inside a `##` section: that section is tagged "Ajustable por el owner / por coordinación" and editable by admin + super admin (owner) or also coordination; the line itself does not render. |
| `{{studio:<key>}}` | A text policy card from `studio_policies` (seed `src/data/seed/studioPolicies.ts`: `lost_items_days`, `opening_lead_minutes`, `closing_checklist_owner`, `guest_allowance_note`, `quiet_hours_note`) with a 44 px edit for the allowed level. **Inside a sentence** it is replaced by the value in bold. An M-08 key (`cancellation_hours`, `late_grace_minutes`…) renders the live M-08 value with "Este valor se cambia en Ajustes" instead. |
| `{{policy:<field>}}` | Live M-08 value (unchanged), plus "Cambiar este valor → Ajustes (M-08a / M-08c)" for editors. |
| `{{source:<id>}}` | The `SourceEmbed` card: `modelo-de-valor`, `contenido-completo`, `manual-de-marca` (`docs/source/index.json`). |
| `{{audience}}` | The "who reads what" matrix from `audience.ts` (with the marketing and developer columns) — replaces the static table in 00-index §4. |
| `{{audience:<slug or number>}}` | One chapter's "Para: …" chip row (required, then recommended ○). |
| `{{training:<role>}}` | That role's Día 1 / Semana 1 / Mes 1 checklist with checkboxes and the stage sign-off (`front_desk`, `teacher`, `coordinator`, `finance`, `admin`, `maintenance`, `marketing`, `developer`; `super_admin` uses admin's). Without an argument: the lens role. |
