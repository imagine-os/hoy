## New and changed contracts

- **Spec (changed).** `PageSpec` gained optional `actions?: ActionDef[]` (declared WebMCP actions) and `checkedAt?: number[]` (the viewport widths a page has been checked at — HUB-01, D-05 and D-06 carry `[360, 390, 768, 1280, 1920, 2560, 3840]`). Neither counts toward `specCompleteness`.
- **Global (changed).** `window.__hoyos` = `{ routes, users, actions, run }`. `actions` is a getter returning `listActions()`; `run(id, params)` resolves `{ ok, message }`. `src/app/manifest.ts` also exports `routeManifest(routes)` and the `HoyosGlobal` type. See `docs/reference/surfaces.md`.
- **Registry (new).** `src/actions/` — `registerActions`, `useActions`, `listActions`, `run`. A page declares in its spec and mounts handlers with the same ids; in dev a mismatch warns on both sides.
- **Frame session (new).** `src/app/frameSession.ts` — `isFramed()`, `hashQuery()`, `liveFramesAllowed()`, `frameUrl(route, opts)`, `installFrameSession()` (called first in `main.tsx`). It shadows only `hoyos.session`, `hoyos.lang`, `hoyos.theme`, and only inside a frame whose hash query asks for it.
- **Toast bus (new).** `src/app/toast.ts` — `toast(text, tone?, ttl?)` / `onToast(cb)`; one `<Toasts/>` in `App.tsx`. Nothing else renders notices.
- **Thumbnails (new).** `npm run thumbnails` (`scripts/screenshots.mjs --thumbs`) writes `docs/screenshots/<CODE>/thumb-<lang>-desktop[-dark].jpg` (640 × 400) and `thumb-<lang>-phone[-dark].jpg` (195 × 422), JPEG q64, one route per page code, both languages, both themes. `src/app/thumbnails.ts` resolves them with a lang → light → Spanish → any fallback chain.
- **Tokens.** `hues` (13 families) → `--hue-site`, `--hue-app`, `--hue-teacher`, `--hue-desk`, `--hue-inbox`, `--hue-pos`, `--hue-admin`, `--hue-crm`, `--hue-finance`, `--hue-manual`, `--hue-docs`, `--hue-kb`, `--hue-dev`, plus `--hue-sat` / `--hue-lum` (light 46 % / 52 %, dark 42 % / 64 %, wireframe 0 %).
- **Build.** `vite.config.ts` defines `__COMPONENT_COUNT__` (declared in `src/vite-env.d.ts`).
- **Components (5 new, 66 in D-02).** `Icon`, `Placeholder` (atoms), `Toast` (molecule), `DeviceFrame`, `PagePreview` (organisms). `usedBy` updated on Badge, Button, Toggle, Wordmark, Input, LangToggle, RoleSwitcher, SegmentedControl, Field, BreathingRings, InspectorPanel.
- **Routes.** `/dev/canvas` (D-05) and `/dev/simulator` (D-06), super_admin, in the design-system nav group at orders 6 and 7. 99 → **101 routes**, 85 → **87 codes**.
- **Placeholders.** The hub's "Reportar un problema" is wrapped in `Placeholder`: in-product annotations are a backlog card, and the control says so instead of pretending.

## Review fixes and QA follow-ups

The build was reviewed before it was committed. **Six bugs found by the review and fixed**: the frame
session shadowed the wrong keys (a preview could read and write the tester's own session) · the shadow
map was a plain object, so `key in shadow` answered true for every `Object.prototype` member and a
`getItem('constructor')` handed back a function (now `Object.create(null)`) · toast timers were never
cleared, so a dismissed toast could fire again over the next one · the toast region was not announced
(it is a live region now) · the "live" tag stayed on a card that lost its budget slot and had not
reloaded (`liveLoaded` resets when the slot goes) · and a failing action returned `{ ok: true }` with an
error string, which an agent reads as "done" (a bad parameter now throws, so `run()` answers
`{ ok: false }`).

**Six follow-ups from the lead's review, applied in this pass**: (a) `src/actions/bus.ts` — the comment
now says what the code does: the effect is keyed on `[spec, impl]`, so callers memoize `impl`.
(b) `PagePreview` computes `mayLive = live && liveFramesAllowed()` itself, so the component — not only
the hub — never boots a frame when framed, under `live=0` or under automation; the doc comment and the
meta say so. (c) The live-budget wording is exact: slots are granted in document order on first paint
and then kept first-come-first-served — a card scrolling in does not preempt a granted one. (d)
`hub.toggleDevMode` and `hub.toggleWireframe` throw `requires super_admin` when the session is not a
super admin, so `run()` answers `{ ok: false }`; `permission` is documented as advisory metadata for
agents (`docs/reference/surfaces.md`, `docs/decisions.md` D-0002). (e) `CanvasPage` lost a dedupe that
could never fire (the key was code + path); one tile per route is the intent and is now a comment.
(f) `Toggle` already draws its focus ring on the track (`.toggle input:focus-visible + .toggle-track`,
`Toggle.css:7`) and already lists `focus` in its meta — left as is, and recorded below.
