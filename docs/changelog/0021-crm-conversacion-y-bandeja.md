## New and changed contracts
- **Table (changed).** `message_log` — new columns `direction`, `source`, `subject`, `body`, `sent_by`, `read_at`, `read_by`, `external_id`; `channel` enum `whatsapp | email | push | note`; `status` enum `received | queued | sent | delivered | read | failed`; `rls` contract added (21 of 48 tables now carry one). Row type `MessageLogRow` with `MessageChannel` / `MessageDirection` / `MessageSource` / `MessageStatus` in `src/data/schema.ts`. **Anything that inserts a `message_log` row must set the new columns** — the four existing sites do.
- **Reseed.** `MockProvider.SEED_VERSION = 2`: a stored demo db with another version (or none) is discarded and reseeded on first load, whatever day it was seeded. Bump it again whenever a column is added that an old localStorage copy would lack.
- **Seam.** `src/data/comms.ts` — `useMessaging()` is the only way a page sends a WhatsApp / email or writes a note; `useConversations()` / `useUnreadInbound()` are the only readers of "who wrote" (S-06, the bell, S-01). A real adapter plugs in here: `SupabaseProvider` for the writes, webhook rows (`direction = inbound`, `external_id`) for the reads.
- **Notes moved.** Staff notes are `message_log` rows (`channel note`, `direction internal`), no longer `audit_log member.note` rows with `diff.note`. Old audit rows stay as history; nothing reads them as notes any more.
- **Components (5 new, 61 in D-02).** `ChatBubble`, `MessageComposer`, `InboxPopover` (molecules), `MessageThread`, `ConversationList` (organisms). `NotificationBell` props `expanded?`, `controls?`; `Timeline` exports `TIMELINE_ICON`. `usedBy` updated on Avatar, Chip, Input, EmptyState, PhoneBubble, SegmentedControl, Timeline, NotificationBell, DesktopShell.
- **Routes.** `/staff/inbox`, `/staff/inbox/:id` (S-06, desk roles, nav order 1.5). 96 → **98 routes**, 84 → **85 codes**.
- **Audit actions.** `member.message` (channel, user_id, source, status — no content), `member.note` (user_id only). `deletion` and the rest unchanged.
- **Strings.** `core.nav.inbox`, `core.notifications.{title,empty,viewInbox,more}`, `core.msg.*`, `staff.inbox.*`, `staff.home.{unread,unread.hint,messages,messages.empty,openInbox}`, `admin.member.tab.conversation`, `admin.member.conversation.*`. Removed: `admin.member.{tab.timeline,tab.notes,timeline.empty,automation,note,notes.rule,notes.ph,notes.add,notes.empty,compose.wa,compose.email,compose.text,compose.unverified,compose.send}`.
