# Communication: WhatsApp and email

WhatsApp is the main channel. Everything the studio sends, automated or by hand, lands on the member timeline in **M-06 CRM**.

## 1. Channel rules
| Rule | Detail |
|---|---|
| One number | The studio's WhatsApp Business; never from personal phones |
| Opt-in | Only opt-in numbers receive automations (captured in A-03 or S-04) |
| Opt-out | "Stop" or "no more messages" is honoured immediately and permanently; recorded in M-06 |
| Quiet hours | 9pm–7am nothing non-urgent is sent; automations queue until 7am |
| Exceptions | Class cancelled by the studio and waitlist spot released always go out |
| Response | During desk hours, under 15 min; outside hours, first thing in the morning |
| Email | Confirmations, receipts with DIAN reference, cancellations; backup to WhatsApp, not a replacement |

## 2. Automated templates (M-05 / M-04)
| Template | Trigger | Timing |
|---|---|---|
| Booking confirmed | booking created | immediate |
| Class reminder | T−2 h | respects quiet hours |
| Class cancelled | studio cancellation | immediate, always |
| Waitlist released | spot released | immediate, always; 30 min to claim |
| Receipt / invoice | payment settled | immediate |
| Membership expiring / charge notice | T−3 days | 8:00 AM |
| Ask for feedback | class attended | same day |
| Happy birthday | date | 8:00 AM |
| Guest invitation | member invites | immediate |
| Payment failed | gateway decline | immediate |

Each template needs Meta approval per language; its status shows in M-05.
**Steps in HoyOS:** M-05 → automation → preview → Meta status → Log. M-04 → template → Send a test.

## 3. Manual messages (front desk)
1. Structure: name + fact on the first line; action on the second; at most one 🌿.
2. Examples:
   - "Hola, <name>. The 7:00 is full; I've put you on the waitlist and will let you know if a spot opens 🌿"
   - "Hola, <name>. We received your transfer, your 3-Class Pack is active. See you soon."
   - "Hola, <name>. Your membership renews on <date> for $520.000. If you want to pause it, tell me and we'll do it."
3. Never send photos of payment proofs, health data or another person's information.
4. Every relevant conversation is summarised as a note in M-06.

## 4. Tone
1. Human, close, direct, present (see `01`). Informal "tú" always.
2. Complaints get first what we can do; the rule is explained afterwards, without blame.
