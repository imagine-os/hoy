# Glossary

## 1. Of the business
| Word | Means | In front of the customer |
|---|---|---|
| Member | person with an active plan or pass | their name, or "member" |
| Pass | a product of the Bienvenida family | "pass" |
| Membership | recurring access, monthly or annual | "membership" |
| Credit | one prepaid class with a validity | "credit" |
| Pausa (product) | a 15–30 min micro-session | "pausa" |
| To pause | to freeze a membership | "pause your membership" |
| Voucher | prepaid money with a code, to give away | "gift voucher" |
| Guest | a Membership member's companion | "guest" |
| Espacio | renting the studio to a third party | "space rental" |
| Movement | Enraíza, Fluye, Arde, Libera | the movement's name |
| Modality | hot yoga, barre, pilates, meditation, breathwork | the class's name |

## 2. Of the operation
| Word | Means |
|---|---|
| Check-in | marking that the person arrived, in S-02 |
| No-show | booked and did not arrive, confirmed in S-02 |
| Late cancellation | cancelled outside the window; the credit is spent |
| Waitlist | the queue for a full class, promoted in order |
| Window | the deadline a policy sets (cancellation, claim, grace) |
| Quiet hours | the band in which nothing non-urgent is sent |
| Cut-off | the day of the month payroll closes |
| Run | the payroll of one cut-off, as draft, approved or paid |
| Payout | the deposit a gateway makes to the studio, or the payment to a teacher |
| Reconciliation | crossing what was charged against what was deposited |

## 3. Of the system
| Word | Means | Don't say |
|---|---|---|
| Screen / code | every screen has a code (S-02, C-04, M-08a) | "the module" |
| Surface | a group of screens: public, member, teacher, team, admin | — |
| Table | where something is stored (`25`) | "the database" |
| Access contract | who may read and write a table | "the db permissions" |
| Activity log | M-07: everything that happened, with actor and time | "the log" |
| Policy | an M-08 value the software enforces | "the rule" |
| Feature / switch | a block that is turned on or off (M-08b) | "the config" |
| Simulated | designed and working, with no vendor connected (`26`) | "fake", "mock" |
| Placeholder | a slot waiting for real content (photo, text, video) | "the missing bit" |
| Directive | a `{{…}}` line this manual replaces with the live value | — |

## 4. The code families
| Family | What for |
|---|---|
| `A-xx` | access and authentication |
| `C-xx` | the member app |
| `S-xx` | the team in the studio (front desk, teachers) |
| `M-xx` | administration |
| `W-xx` / `P-01` | the public site |
| `E-xx` | edge states (empty, declined, cancelled, locked) |
| `D-xx` | design and tooling |
| `K-xx` | knowledge: this manual (K-03), decisions (K-04), the changelog (K-01) |
