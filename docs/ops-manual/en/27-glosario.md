# Glossary

The studio's words, on one page. If a word in this manual isn't here, ask coordination to add it.

{{audience:27-glosario}}

## 1. Business
| Word | What it means | In front of customers we say |
|---|---|---|
| Member (socio) | someone with an active plan or pass | their name, or "member" |
| Pass | a product from the Welcome line | "pass" |
| Membership | access that renews, monthly or yearly | "membership" |
| Credit | a prepaid class, with an expiry date | "credit" |
| Pause (product) | a short 15 to 30-minute session | "pause" |
| Unlimited Pauses | a monthly add-on that stacks with Membership | "unlimited pauses" |
| Pausing | freezing a membership | "pausing your membership" |
| Voucher | prepaid money with a code, to give as a gift | "gift voucher" |
| Guest | someone a Membership member brings along; included, not charged | "guest" |
| Space | renting the studio to a third party | "renting the space" |
| Special | a sale with the concept and price typed by hand (birthday, team session, rental with extras) | the concept: "your private session" |
| Corporate Experiences | the sixth line, **in preparation**: wellbeing for work teams (team session, recurring programme, tailored workshop) | "we're preparing a programme for teams" |
| Discipline | hot yoga, barre, pilates, meditation, breathwork: each class's public name | the class name |
| Movement | Enraíza, Fluye, Arde, Libera: the internal label that shapes the day | not used with customers |

## 2. Operations
| Word | What it means |
|---|---|
| Check-in | marking that the person has arrived |
| No-show | booked and didn't come |
| Late cancellation | cancelled outside the window; the credit is used |
| Waitlist | the queue for a full class; the spot is offered in order |
| Window | the time limit a policy sets (cancellation, waitlist, grace) |
| Quiet hours | the hours when nothing non-urgent is sent |
| Pay period | the month or fortnight teachers are paid for |
| Pay run | the payroll for one period: draft, approved or paid |
| Payout | the deposit Wompi makes to the studio, or the payment to a teacher |
| Reconciliation | comparing what was charged with what reached the bank |

## 3. System
| Word | What it means | Don't say |
|---|---|---|
| Screen | each place in HoyOS; in the In HoyOS boxes it appears with its code | "the module" |
| Surface | a group of screens: website, member app, teacher app, team, admin | — |
| Table | where something is kept ([25](25-datos-y-tablas.md)) | "the database" |
| Activity log | everything that happened, with who and when | "the log" |
| Policy | a value in Settings the system applies on its own | "the rule" |
| Feature | a block that is switched on or off in Settings | "the config" |
| Simulated | designed and working, but without the provider connected ([26](26-integraciones.md)) | "fake" |
| Provisional | a slot waiting for real content (photo, text, video) | "what's missing" |
| Editable | a section of this manual the owner or coordination adjusts | — |
| Live block | a box in this manual that shows the system's current value | — |

## 4. How to read the codes
The **In HoyOS** boxes name screens by their code. The letter tells you which part of the system it belongs to:

| Code | Part |
|---|---|
| `A-xx` | signing in and creating an account |
| `C-xx` | the member app |
| `S-xx` | the team in the studio (front desk, teachers) |
| `M-xx` | administration |
| `W-xx` / `P-01` | the public website |
| `E-xx` | special cases (empty, declined, cancelled, locked) |
| `D-xx` | design and developer tools |
| `K-xx` | this manual, its decisions and the change history |
